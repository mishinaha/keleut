### 退行の探索

試作の差分は無いので、HEAD と試作の出力の差は生じない。
代わりに、境界の形で「閉じた空行は `@ {}`、裸の行変数は `@` なし」が崩れないかを HEAD で測った(`verify/ex/`、出力は `verify/head.out`)。

- エイリアス(e1): `type Pure = (Int32) => Int32` の値束縛は `@ {}`、`type W: EffectRow = {}` は `@ {}`、`@ {W extends E}` は裸の `E` になり `@` なし。
- module(e2): `pub let M.f` は `@ {}`、非 pub の `M.g` は `@` なし。`let u = M.f` は名前の参照で尾部が開き `@` なし(§13.2 の使用時の開き)。
- 型クラス(e3): `let s = size` は `[A: Sz] (A) => Int32`(名前の参照で開く)。
- ハンドラの入れ子と弱い変数(e4): `weak` と `lam` はどちらも `() => Int32` で区別されない。これは show.ml §9.6 の記事が「表示が同じで意味が違う組」として挙げる既知の性質で、本項目の範囲(閉じた空行と行変数)の外である。
- 型パラメータと入れ子の矢印(e5、e8): `ap0` の仮引数の `@ {}`、`curry` の返り値の矢印の `@ {}` が出る。ガードの中で呼ぶ `pick` の仮引数も `@ {}`。
- REPL(e6): `f`、`h` は `@ {}`、`g`、`w` は `@` なし。`w()` の後の `w` は弱い行が `{Console, Blocking, Print extends _R1}` に決まって表示される。
- プレリュードの差し替え(e7)と import(imp/main.kel): pub の関数を名前で参照すると `@` なし、`@ {}` と注釈した束縛は `@ {}`。
- 診断の中(e10〜e12): `f: () => Int32 @ {}` を名前で参照した値は `() => Int32` と出る(使用時の開き)。剛な行変数 `E` で終わる行は `{Console extends ς1}` と出る。

崩れる形は見つからなかった。
剛な行変数を `ς1` と表示する点は、X-regionshow(リージョンパラメータの表示の命名)と同じ命名の話で、本項目の判定には影響しない。

### 重なり

- X-regionshow: 同じ `lib/show.ml` の命名(`ς`、`_R1`)を触る可能性がある。`eff_row` の尾部の表示(e12 の `ς1`)に波及しうる。本項目は変更なしなので衝突はしない。
- X-D74、X-perform、X-premise、V33、V34: 型を含む診断文を変える項目で、`@ {}` の表示を含む期待値(`annot_rows.t` など)を動かしうる。本項目は観測点として `annot_rows.t` の val2 と val1 を挙げるだけなので、それらの項目がこの 2 ブロックを変えないことを統括者が確かめればよい。
