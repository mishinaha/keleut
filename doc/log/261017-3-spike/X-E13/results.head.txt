### 既定の上限での閾値の探索(HEAD)
入れ子の深さ n の `let x = 1 + (1 + (... 1 ...))` を、--dump-ast、--type-check、実行の 3 通りで走らせた。
- OCAMLRUNPARAM=l=100k:n = 2000、3000、5000 はすべて終了状態 0。n = 10000 は --dump-ast が 0、--type-check と実行が 3(実行時エラー: スタックオーバーフロー(再帰が深すぎます))。
- 既定の上限:n = 10000、100000、1000000(ファイル 6 MB)のどれも 3 通りとも終了状態 0。n = 1000000 の実行は約 25 秒。
- `let x = ((...(1)...))`(括弧だけの入れ子)は l=100k の n = 10000、既定の n = 100000 でも 0。
