## 退行

試作は、未知のクラスと予約述語の診断より先に曖昧性の診断を出す。
`let` の側は未知のクラスと予約述語を先に出すので、束縛とそろえるという推奨の趣旨に反する。

- r10_bogus.kel: `type class C3[A] { val m[B: Bogus]: (A) => A }`。HEAD は `未知のクラス: Bogus`、試作は `曖昧な制約: メソッド m の型パラメータ B の制約 Bogus を…`。束縛の r10_letbogus.kel は両方で `未知のクラス: Bogus`。
- r11_frac2.kel: `type class C4[A] { val m[B: Show + Fractional]: (A) => A }`。HEAD は `Fractional は予約されたリテラル述語です(制約には書けません、D8)`、試作は `曖昧な制約: … 制約 Show を…`。束縛の r11_letfrac2.kel は両方で予約述語の診断。
- r5_dup.kel: メソッドの重複と型に現れない制約の両方を持つ宣言は、HEAD は `メソッド pp が二重に宣言されています`、試作は曖昧性の診断になる。

原因はソースから読める。
未知のクラスと予約述語の検査は、elab.ml 4823-4834 行の 1b の後始末(`class_names_of`)で、`register_class` より後に走る。
下書き (6) の「予約述語は先に別の診断で落ちる(c13)ので、`is_predicate` の除外は防御である」は誤りで、r11_frac.kel(`[B: Fractional]` だけ)で予約述語の診断が出るのは、この除外があるからである。

意図どおりの変化(推奨案の帰結)として、次の形も HEAD の受理から試作の拒否に変わる。
r1_phantom.kel(使わないパラメータのエイリアス `Const[B]` だけに現れる形。束縛の r1_letphantom.kel は HEAD でも拒否)、r6_guard.kel(`[B: Ord]`、本体にガード)、r13_later.kel(後ろで宣言するクラスを制約にする形)、REPL(クラスの宣言が拒否され、続くインスタンスが `未知のクラス: Pp`、使用が `未束縛の変数: pp` になる)、r4_import.kel(import 先の lib/cls.kel:1:1 で拒否)、--prelude に渡した利用者のプレリュード(pre_user.kel:1:1 で拒否)。
いずれも推奨案の規則どおりで、§18.5 とも合う(拒否した入力は後から見えない)。

型に現れる形の誤検出は見つからなかった。
入れ子の矢印の引数だけに現れる形(r15_nested.kel)、返り値の型引数だけに現れる形(r16_ret.kel)、`Heap[B]` の行の中だけに現れる形(r2_heap.kel。束縛の r2_letheap.kel も受理)は両方で受理し、出力も同じである。
