### 誤った案内が残る形(実測)

D[V34-2] の案内「外側で宣言した行変数を注釈に書くか、注釈を省いてください」は、空の行が初期化式の側にあると実行できない。

```
let ap(h: () => Int32 @ {}): Int32 = h()
let f[E](g: () => Int32 @ E): Int32 @ E = {
  let k: (() => Int32 @ E) => Int32 = ap
  k(g)
}
```

試作は `q1.kel:3:7: … 空の行と一致させられません)(値束縛は型パラメータを取れません。行を通すなら、外側で宣言した行変数を注釈に書くか、注釈を省いてください)` を出す。
注釈には `E` が既に書かれている。
注釈を省いた `q1omit.kel` は 4:5 で落ちる。
直すのは `ap` の側である。

D[V34-3] の案内も、実装に注釈が無いときに出る。


### 判断事項について

P[V34-1] の D[V34-1](単一化の文言から助言を外す)には異論が無い。

見落とされた代案は 2 つある。

ただし、インスタンスの `let rec` の値束縛は D[V34-3] の案内を受けるので、根拠の文面をそれに合わせる必要がある。
