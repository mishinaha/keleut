## 4. 指摘

1. N.2 (5) の「4 ブロック、6 プログラム」は「4 ブロック、5 プログラム(コマンド 7)」に直す。
2. N.z の「lib/exhaust.ml 68 行の追加」は「65 行の追加と 3 行の削除」に直す(never_ops.t も「76 行の追加と 3 行の削除」と書くと揃う)。N.1 (1) の「31 行の追加」も V134.patch の実数(34 行の追加と 2 行の削除)に直す。

4. 合成で書き換えた V129 の記事の文「上の規則で Never に決めない」は、V134 の §10.13 の段落(N.1 (5) のソースコメントで足す予定)を指すが、合成差分にはその段落がまだ無い。N.2 (5) に、V134 の段落を先に書くことを前提とする旨を足す。
