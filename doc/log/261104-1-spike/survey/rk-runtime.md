## 実測した結果

終了状態はどれも同じ(3)だった。interp・jit・wasm の 3 つの後段は全件で一致した。`--frontend diktor` と `--tier alternating=3` も同じ綴りだった。

| 試験 | Diktor | keleut の 3 つの後段 |
| --- | --- | --- |
| t1: 型 `{b, a}` の照合の失敗に `{a = 1, b = 2}` を渡す | `{a = 1, b = 2}` | `{b = 2, a = 1}` |
| t2: `{c = 3 extends base}` | `{c = 3, a = 1, b = 2}` | `{a = 1, b = 2, c = 3}` |
| t3: 前に `let q = {a = 7, b = 8, c = 9}` があり、`{b = 1, a = 2, c = 3}` を渡す | `{b = 1, a = 2, c = 3}` | `{a = 2, b = 1, c = 3}` |
| t3b: t3 から q を除いたもの | `{b = 1, a = 2, c = 3}` | `{b = 1, a = 2, c = 3}`(一致) |
| t4: 入れ子のレコード | `{y = {b = 1, a = 2}, x = 3}` | 一致 |
| t5: ヴァリアントの中のレコード `#P({a = 2, b = 1})` | `#P({a = 2, b = 1})` | `#P({b = 1, a = 2})` |
| t8: コンストラクタの中のレコード | `Box({b = 1, a = 2})` | 一致 |
| t10: 組の中のレコード | `({a = 1, b = 2}, 3)` | `({b = 2, a = 1}, 3)` |
| t6: 組 `(1, "s", false)` | 一致 | 一致 |
| t7: 同じラベルの重複 `{x = 1 extends {x = 2, y = 3}}` | `{x = 1, x = 2, y = 3}` | 一致 |
| t9: 更新 `{q with x = 5}` | `{y = 1, x = 5}` | 一致 |
| t11: 組の拡張 `{z = 3 extends (1, 2)}` | `{z = 3, _item = 1, _item = 2}` | `{_item = 1, _item = 2, z = 3}` |
| t12: 更新してから拡張 | `{b = 0, a = 2}` | `{a = 2, b = 0}` |

- t1 で `b` が先になるのは、関数 f のパターンが `b` を先に書いていて、下ろしがそこで `b` に先に番号を振るからだと推測する。
- t3 と t3b の差は、前にある別のレコードで綴りが変わることを示す。
- t4 と t8 が一致したのは、パターンに書いた順(`b` が先)と Diktor の作った順がたまたま揃ったためで、偶然である。
- 中身を書き換えて同じ綴りを保つ場合は一致する(t9 の更新、t7 の同じラベルの重複)。拡張は一致しない(t2、t11、t12)。
